## Installation

El código tiene definidas diferentes clases (banco y cliente).
La cuenta bancaria tiene una cantidad de dinero ya metida a la que se le puede meter o quitar cantidades de dinero ya definidas en el código. El programa devuelve la cantidad que queda en la cuenta y el nombre del propietario de la misma.
